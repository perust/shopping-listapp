## 1. 배경 및 문제 정의

논문, 보고서, 계약서, 매뉴얼 등 PDF 문서는 분량이 많아 전체를 읽기 전에 **핵심을 빠르게 파악할 방법**이 필요하다. 기존 상용 요약 서비스는 회원가입·유료 구독·문서 서버 업로드를 요구하며, 이는 두 가지 장벽을 만든다.

1. **비용/접근성 장벽** — 가입과 결제 없이 즉시 쓸 수 없다.
2. **기밀성 우려** — 문서 파일 자체가 외부 서버에 저장된다.

본 제품은 **설치·서버·가입 없이 HTML 파일 하나를 더블클릭하면 동작**하고, **PDF 파일 원본은 절대 외부로 전송하지 않으며**, 브라우저 안에서 추출한 텍스트만 AI 모델에 보내 요약을 받는 도구다.

## 2. 목표 / 비목표

### 2.1 목표 (Goals)
- G1. 사용자가 PDF를 드래그&드롭하면 **3단계 이내**(끌어놓기 → 요약 버튼 → 결과)로 요약을 얻는다.
- G2. 텍스트 추출은 **100% 브라우저 로컬**에서 수행한다. 파일 바이너리는 네트워크로 나가지 않는다.
- G3. **무료 모델만** 사용하여 사용자 추가 비용이 0원이다.
- G4. 전체 UI·요약 결과가 **한국어**다. 영문 PDF를 넣어도 요약은 한국어로 나온다.
- G5. 단일 `.html` 파일로 배포되어 빌드 도구·패키지 매니저·로컬 서버가 필요 없다.

### 2.2 비목표 (Non-Goals)
- N1. 스캔 이미지 PDF의 OCR — v1 범위 밖. 감지하여 안내만 한다.
- N2. 다중 파일 동시 요약(배치) — v1은 1회 1파일.
- N3. 요약 이력의 서버 저장·계정 동기화.
- N4. DOCX/PPTX/HWP 등 PDF 외 포맷.

## 4. 아키텍처 결정 및 근거

`index_pdf.html`을 **브라우저에서 직접 연다(`file://`)**는 요구사항이 아키텍처를 결정한다. 서버가 없으므로 API 프록시를 둘 수 없고, 브라우저가 API를 직접 호출해야 한다. 사전 검증 결과는 다음과 같다.

| 검증 항목 | 결과 | 설계 반영 |
|---|---|---|
| OpenRouter CORS (`Origin: null`) | ✅ `access-control-allow-origin: *` | 브라우저에서 직접 호출 |
| NVIDIA API 직접 호출 (`integrate.api.nvidia.com`) | ❌ CORS 헤더 없음 → 브라우저 차단 | **OpenRouter 경유로 NVIDIA 모델 사용** |
| PDF.js CDN (cdnjs / jsDelivr) | ✅ 200 | 이중 CDN 폴백 |
| 리즈닝 모델의 `content` 오염 | 사고 과정이 본문에 섞임 | `reasoning:{enabled:false}` 전송 |

> **결정 D-1 (개정)**: NVIDIA 무료 모델을 **1순위 제공자**로 사용하며, CORS 제약 때문에 최소 로컬 프록시(`nvidia_proxy.py`)를 경유한다. 프록시가 없으면 OpenRouter로 자동 대체한다.
>
> 개정 이유: 초판에서는 "NVIDIA 모델을 OpenRouter를 통해 호출"하기로 했으나, OpenRouter 무료 티어의 하루 50회 제한이 실사용을 막았다. NVIDIA API는 별도 할당량을 가지므로 프록시를 도입해 직접 사용한다. `index_pdf.html`을 더블클릭으로 여는 요구사항은 그대로 유지된다 — `file://` 페이지에서 `http://127.0.0.1:8770` 호출이 가능함을 실측으로 확인했다.
>
> **결정 D-2**: 텍스트 추출은 PDF.js로 브라우저에서 수행한다. 서버 업로드가 없으므로 G2(기밀성)가 구조적으로 보장된다.
>
> **결정 D-3 (개정)**: OpenRouter 키만 HTML에 내장한다. **NVIDIA 키는 내장하지 않고** 프록시가 `.env`에서 읽어 요청 시점에 주입한다. 프록시 경유 경로에서는 키가 브라우저에 전혀 노출되지 않는다.

### 4.2 제공자 비교

| | NVIDIA API | OpenRouter |
|---|---|---|
| 브라우저 직접 호출 | ❌ CORS 미허용 | ✅ `ACAO: *` |
| 필요 조건 | `nvidia_proxy.py` 실행 | 없음 |
| API 키 위치 | `.env` (HTML에 없음) | HTML에 내장 |
| 사용량 제한 | 계정 크레딧 | **하루 50회** |
| 자동 선택 우선순위 | 1순위 | 2순위 (대체) |

### 4.1 처리 파이프라인

```
[파일 선택/드롭]
   → 검증 (확장자·MIME·크기·매직넘버)
   → PDF.js 파싱 (암호화·페이지수 확인)
   → 페이지별 텍스트 추출 (진행률 %)
   → 텍스트 품질 판정 (스캔본 감지)
   → 청킹 (문단 경계 우선 분할)
   → [1청크] 단일 요약  |  [N청크] map-reduce 요약
   → 결과 정규화(JSON) → 렌더링
```

## 5. 기능 명세

### FR-1. 파일 입력
- FR-1.1 드래그&드롭 영역에 PDF를 놓아 업로드한다. 드래그 중 영역이 시각적으로 강조된다.
- FR-1.2 영역 클릭 또는 키보드 `Enter`/`Space`로 파일 선택 대화상자를 연다.
- FR-1.3 페이지 전체 어디에 드롭해도 파일이 브라우저 기본 동작(새 탭 열기)으로 새지 않는다.
- FR-1.4 파일 교체 시 이전 결과·상태가 완전히 초기화된다.

### FR-2. 파일 검증
| 규칙 | 조건 | 사용자 메시지 |
|---|---|---|
| V-1 | 확장자가 `.pdf`가 아님 | "PDF 파일만 업로드할 수 있습니다." |
| V-2 | 파일 크기 0바이트 | "빈 파일입니다." |
| V-3 | 파일 크기 > 50MB | "파일이 너무 큽니다 (최대 50MB)." |
| V-4 | 헤더가 `%PDF-`가 아님 | "손상되었거나 PDF 형식이 아닌 파일입니다." |
| V-5 | 비밀번호로 암호화됨 | "비밀번호로 보호된 PDF는 요약할 수 없습니다." |
| V-6 | 추출 텍스트가 임계치 미만 | "텍스트를 추출할 수 없습니다. 스캔 이미지 PDF로 보입니다." |

### FR-3. 텍스트 추출
- FR-3.1 PDF.js로 페이지별 텍스트를 추출하고, 진행률을 `현재/전체 페이지`와 % 로 표시한다.
- FR-3.2 같은 줄에 속한 텍스트 조각은 붙이고, y좌표가 바뀌면 줄바꿈하여 **단어 붙음 현상**을 방지한다.
- FR-3.3 추출 결과에서 과도한 공백·제어문자를 정리한다.
- FR-3.4 페이지 단위 추출 실패는 해당 페이지만 건너뛰고 전체를 중단하지 않는다.
- FR-3.5 추출 완료 후 페이지 수·글자 수·예상 처리 방식(단일/분할)을 표시한다.

### FR-4. AI 요약
- FR-4.1 요약 길이 3단계: **짧게**(3줄 내외) / **보통**(기본) / **자세히**.
- FR-4.2 출력 구성: ① 한 줄 요약 ② 핵심 포인트 목록 ③ 상세 요약 ④ 키워드 태그.
- FR-4.3 긴 문서는 청크로 분할 → 청크별 부분 요약(map) → 부분 요약 통합(reduce).
- FR-4.4 **모델 폴백 체인**: 우선 모델이 429/5xx/타임아웃이면 다음 무료 모델로 자동 전환하고, 실제 사용된 모델명을 결과에 표시한다.
- FR-4.5 모든 모델 실패 시 원인별 한국어 오류 메시지와 **다시 시도** 버튼을 제공한다.
- FR-4.6 요약 중 **취소**할 수 있다.
- FR-4.7 원문 언어와 무관하게 **요약은 항상 한국어**로 생성한다.

### FR-5. 결과 표시 및 활용
- FR-5.1 한 줄 요약은 강조 카드로, 핵심 포인트는 번호 목록으로, 키워드는 태그 칩으로 표시한다.
- FR-5.2 **전체 복사** 버튼 — 클립보드에 Markdown 형식으로 복사.
- FR-5.3 **Markdown 다운로드** 버튼 — `{원본파일명}_요약.md`로 저장.
- FR-5.4 **추출 원문 보기** 토글 — 추출된 텍스트 전문을 접이식 영역에서 확인.
- FR-5.5 처리 정보 표시: 사용 모델, 소요 시간, 페이지 수, 글자 수.

### FR-6. 설정
- FR-6.1 API 키 입력란 — 비워두면 내장 키 사용, 입력하면 해당 키 사용(`localStorage` 저장).
- FR-6.2 모델 선택 — 자동(폴백 체인) 또는 특정 무료 모델 지정.
- FR-6.3 다크/라이트 테마 자동 감지 및 수동 전환.

## 7. 에러 처리 매트릭스

| 상황 | 감지 방법 | 사용자 메시지 | 복구 |
|---|---|---|---|
| 비-PDF 파일 | 확장자 + 매직넘버 | "PDF 파일만 업로드할 수 있습니다." | 다시 선택 |

| 네트워크 단절 | `TypeError: Failed to fetch` | "네트워크에 연결할 수 없습니다." | 재시도 |
| 타임아웃 | `AbortController` 120초 | "응답이 지연되어 중단했습니다." | 재시도 |

| OpenRouter 무료 티어 | **하루 50회** (`free-models-per-day`). 초과 시 모델을 바꿔도 소용없어 즉시 중단하도록 처리 |
| NVIDIA 직접 API | 브라우저에서 `TypeError: Failed to fetch` (CORS 미허용) — 결정 D-1이 유효함을 실측으로 재확인 |
| `file://` 보안 컨텍스트 | Chrome에서 `isSecureContext === true` → 클립보드 API 사용 가능 |
